This page exists only to smoke-test the runner in isolation during development. The real app (frontend/) loads this WASM module directly instead of using this page. Open the console and call window.__runCSharp({ languageVersion, files }) from a real user gesture (e.g. a button click) — calling it via devtools/automation injection for a *second* time can hang the single-threaded WASM interpreter; a normal page's own event handlers don't have this problem.
